
# KL Left-Cell Optimization

SageMath implementations for optimization of
base-change matrices in Specht modules.

Includes evacuation intertwining constraints,
last-letter tableau ordering, and direct
optimization over upper-unitriangular matrices.

# Based on the KL left-cell optimizer by Tom Goertzen.
# Original repository:
# https://github.com/TomGoertzen/canonical-basis-optimizer
#
# Associated publication:
# T. Goertzen and G. Williamson,
# Kazhdan-Lusztig Basis and Optimization (2026).
#
